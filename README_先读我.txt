俄语学习工房 Windows 试用版

使用方法：
1. 解压整个压缩包。
2. 双击 RussianLearning.exe 启动。
3. 不要单独移动 exe，必须让 RussianLearning_Data、MonoBleedingEdge、UnityPlayer.dll 等文件和 exe 保持在同一个文件夹里。

说明：
- 这是当前开发进度的测试版，不是最终上架版本。
- App 内置基础离线词库，可以直接试用。
- 等级页里的“下载词包”会从云端获取词包并缓存到本机；前提是云端 OSS 词包已经上传并公开可读。
- 学习进度会保存在本机，不会自动上传。

如果启动失败：
- 先确认压缩包已经完整解压。
- 尽量放到英文路径或普通中文路径下运行，不要放在权限很严格的系统目录里。
- Windows 安全提示时选择“仍要运行”。
